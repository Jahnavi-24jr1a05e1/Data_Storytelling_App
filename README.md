# 🏏 IPL Data Storytelling App

## 📌 Project Overview

This project presents a data-driven story of the Indian Premier League (IPL) from 2008 to 2022. Using visualizations and exploratory data analysis, the application highlights tournament growth, team performance, venue popularity, and player achievements.

The goal is to transform raw IPL match data into meaningful insights and findings.


## 🎯 Objectives

- Explore IPL match data from 2008 to 2022.
- Identify trends in tournament growth.
- Analyze team performance and success.
- Discover popular IPL venues.
- Highlight top-performing players.
- Present insights through storytelling and visualizations.


## 📊 Dataset Information

**Dataset:** IPL Matches 2008–2022

**Total Records:** 950

**Total Columns:** 20

### Important Columns

- Season
- Team1
- Team2
- Venue
- TossWinner
- WinningTeam
- Player_of_Match


## 🔍 Exploratory Data Analysis (EDA)

The following analyses were performed:

- Dataset overview
- Missing value analysis
- Statistical summary
- Season-wise match distribution
- Team performance analysis
- Venue analysis
- Player performance analysis


## 📈 Story Highlights

### Story 1: Growth of IPL

Analyzed how the number of IPL matches changed across seasons and how the tournament expanded over time.

### Story 2: Most Successful Teams

Identified teams with the highest number of match wins.

### Story 3: Popular IPL Venues

Explored stadiums that hosted the highest number of matches.

### Story 4: Star Performers

Analyzed players with the most Player of the Match awards.


## 💡 Key Findings

- IPL has grown significantly since its launch.
- A few teams consistently dominate the tournament.
- Certain venues host a majority of IPL matches.
- Some players repeatedly deliver match-winning performances.
- Data analysis helps reveal long-term trends in team and player performance.


## ✅ Conclusion

The IPL has evolved into one of the world's most successful cricket leagues. Through data storytelling, we can better understand tournament growth, team success patterns, venue importance, and player contributions.
